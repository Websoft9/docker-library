## Optional PostgreSQL

The container can bundle a PostgreSQL database. Enable it from the app `.env` by
uncommenting one line:

```
COMPOSE_PROFILES=postgres
```

Then rebuild. This starts the `postgres` service and activates the Spring
`postgres` profile, which reads `SPRING_DATASOURCE_*` from the environment.

To use the database from code, add `spring-boot-starter-jdbc` (or `-data-jpa`)
and the PostgreSQL driver; they are already provided by the `postgres` Maven
profile, so run Maven with `-Ppostgres` when you need them:

```bash
mvn -Ppostgres test
mvn -Ppostgres spring-boot:run
```
